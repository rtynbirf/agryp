# Конституция agryp

Версия 1.0 · 2026-11-06 · действует с первого коммита

## Преамбула

Мы строим процессный слой для AI-агентов по этике Linux From Scratch:
понять слой — значит написать слой. Поэтому конституция здесь — не
манифест, а список инвариантов. Каждая статья содержит команду проверки;
статья без команды проверки — не статья, а лозунг, и лозунги в этом
репозитории запрещены. Нарушенная статья — это баг, а не «особенность».

Разделы: **I. Тело** (что мы собой представляем физически),
**II. Дело** (как ведём себя с процессами), **III. Люди** (для кого
это написано), **IV. Поправки** (как меняется сама конституция).

---

## I. Тело

### Ст. 1 — Один файл

Весь продукт — один файл C: `src/agryp.c`, читаемый сверху вниз за один
присест. Потолок — 512 строк: превысил — сначала упрощай, потом добавляй.

Проверка: `find . -name '*.c' | wc -l` → `1`;
`wc -l src/agryp.c` → не больше 512 (сейчас 377).

### Ст. 2 — Ноль зависимостей

Только libc. Ни пакетных менеджеров, ни рантаймов, ни сети при сборке.
PID 1 не имеет права требовать, чтобы мир сначала поставил себе экосистему.

Проверка: `ldd agryp` → только `libc.so.6` (+ vDSO и загрузчик).

### Ст. 3 — Сборка одной командой, без единого предупреждения

`make` — всё. Флаги: `-O2 -Wall -Wextra -std=c99`. Предупреждение
компилятора трактуется как ошибка сборки, а не как фон.

Проверка: `make clean && make 2>&1 | grep -i warning` → пусто.

## II. Дело

### Ст. 4 — Агент — это процесс

Супервизор знает об агенте только то, что знает ОС: pid, код выхода,
время, бюджет. Никаких фреймворков, протоколов, «интеграций» и API-ключей.
Агент, которого нельзя запустить через `sh -c`, — не наш клиент.

Проверка: `grep -n "execl" src/agryp.c` → один вызов, `/bin/sh`.

### Ст. 5 — Не копировать

Мы не пере-делываем systemd/supervisord (знают процессы, но не агентов)
и не оборачиваем фреймворк-оркестраторы (знают агентов, но умирают вместе
с процессом). Ниша доказана цифрами — топ-100 GitHub на 2026-11-06:
агентский стек 40/100, процессного слоя 0/100. Берём доказанные идеи
(init-цикл, юниты, журнал), строки пишем свои.

Проверка: `grep -RniE "systemd|langchain|langgraph" src/` → пусто;
раскладка по категориям — `docs/top100-by-category.md`.

### Ст. 6 — Ничего не происходит молча, журнал не лжёт

Каждое значимое событие — одна строка JSON в stdout: `boot`, `spawn`,
`spawn-fail`, `exit`, `restart`, `stopped`, `budget-kill`, `shutdown`,
`summary`. Числа summary обязаны сходиться с потоком событий; `up_ms`
идёт по монотонным часам; ноль NUL-дыр — `O_APPEND` наследуется детьми
через fork+exec, записи атомарны.

Проверка: `make audit` → `OK` (аудитор `demo/audit_transcript.py`
сверяет каждый счётчик summary со всей хронологией событий).

### Ст. 7 — Бюджет — закон

У каждой попытки объявлен бюджет времени (`budget-sec`; `0` — тоже
объявление: «без лимита»). Перерос — SIGKILL и событие `budget-kill`.
Никто не жжёт CPU и деньги бесконечно.

Проверка: `grep -c '"event":"budget-kill"' demo/demo-transcript.jsonl`
→ `2` в демо, и оба доложены в summary как `budget_kills`.

### Ст. 8 — Политика перезапуска объявлена явно

`restart = always | on-failure | no`, плюс скучные числа `cooldown-ms`
и `max-attempts` (`0` = без лимита). Поведение после смерти описывает
человек, а не эвристика; «умных» алгоритмов backoff здесь нет и не
будет без поправки к конституции.

Проверка: в каждом юните `examples/` есть ключи `restart`,
`budget-sec`, `cooldown-ms`:
`grep -H -E "restart|budget-sec|cooldown-ms" examples/*.agent`.

### Ст. 9 — PID 1 не умирает первым и не бросает детей

Собственный выход — только graceful: SIGTERM → 3000 мс прощания
(`GRACE_MS`) → SIGKILL → summary. Детей не бросаем: попытка — это
группа процессов (`setpgid` в ребёнке и в родителе, kill по `-pgid`),
зомби собирает `waitpid(-1)`, в контейнере agryp усыновляет
осиротевшие процессы.

Проверка: `bash demo/run_demo.sh` в конце сам считает сирот — ноль;
хвост транскрипта — `shutdown`, затем `summary` по каждому юниту,
затем `uptime-ms` (аудит — Ст. 6).

## III. Люди

### Ст. 10 — Тест ἰδιώτης: софт для частника

Юнит читается рядовым человеком без докторской степени — 4–8 строк.
README читается за один присест. Имя без культурного багажа и сленговых
ловушек. Мы — «частники» в исходном смысле слова ἰδιώτης: не комитет,
не платформа, не консорциум.

Проверка: `wc -l examples/*.agent` → не больше 8 строк в каждом.

### Ст. 11 — Ограничения объявлены честно

Константы живут в коде с именами, а не в скрытой магии:
`MAX_UNITS 64`, `GRACE_MS 3000`, `EXEC_LEN 512`, `NAME_LEN 64`.
Упёрся в потолок — говори вслух ошибкой или событием в журнале,
не режь молча.

Проверка: `grep -n "MAX_UNITS\|GRACE_MS\|EXEC_LEN\|NAME_LEN" src/agryp.c`.

## IV. Поправки

### Ст. 12 — Как меняется эта конституция

Статья меняется одним атомом: правка кода + правка статьи + команда
проверки — всё вместе, одним коммитом. Статья без команды проверки —
не статья. Новая функциональность без статьи — не функциональность,
а инцидент. Единственная форма доказательства — демо-транскрипт;
фразы «должно работать» в суде не принимаются.

Проверка: `make demo && make audit` → транскрипт пересоздан, аудит `OK`.
