# Тикет 002 · Аудитор знает ctl-события

Роль: ЯДРО (аудиторская часть). Зависит от: тикет 001. Статус: open. Виток: 5.

## Задача

`demo/audit_transcript.py`:

- события `ctl-down` / `ctl-up` — в `VALID_EVENTS`;
- дисциплина: после `ctl-down` юнита спавнов этого юнита не бывает, пока
  не пришёл `ctl-up`;
- `ctl-up` возвращает юнит в обычную политику: следующий exit → рестарт
  по лестнице (Ст. 8), ступени сходятся как раньше.

## Приёмки

1. `make audit` на демо тикета 001 → OK.
2. Отрицательный тест: подклеенный в транскрипт spawn после `ctl-down`
   без `ctl-up` → FAIL (аудитор ловит подделку).
