# Тикет 002 · Аудитор знает ctl-события

Роль: ЯДРО (аудиторская часть). Зависит от: тикет 001. Статус: done
(2026-11-07). Виток: 5.

## Задача

`demo/audit_transcript.py`:

- события `ctl-down` / `ctl-up` — в `VALID_EVENTS`;
- дисциплина: после `ctl-down` юнита спавнов этого юнита не бывает, пока
  не пришёл `ctl-up`;
- `ctl-up` возвращает юнит в обычную политику: следующий exit → рестарт
  по лестнице (Ст. 8), ступени сходятся как раньше.

## Отчёт (2026-11-07, Виток 5)

Изменения:

- `VALID_EVENTS` += `ctl-down`, `ctl-up`, `ctl-drop`;
- дисциплины: (1) спавн при живом .down → FAIL «политика заморожена»;
  (2) `ctl-up` без `ctl-down` → FAIL «журнал лжёт»; (3) казнённая
  ctl-down попытка обязана получить exit и остановиться с
  `reason:ctl-down` — иначе FAIL;
- `demo/negative_ctl_test.py` — отрицательный тест: эталонный
  ctl-транскрипт проходит аудит; две подделки (spawn при живом .down;
  ctl-up без ctl-down) ловятся с точными формулировками.
