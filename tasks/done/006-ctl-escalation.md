# Тикет 006 · Эскалация ctl-stop: TERM → GRACE_MS → KILL

Роль: ЯДРО (контракт — AGENTS.md §3). Статус: open. Виток: 6.
Зависит от: тикет 001 (done, Виток 5). Слепая зона ТЗ-5 §5 закрыта этим тикетом.

## Задача

Школа systemd (`TimeoutStopSec`): команда stop обязана довести юнит до
смерти даже если агент игнорирует SIGTERM:

- в `unit_t`: `long long ctl_since_ms` — момент появления `.down`;
- ядро в `poll_ctl()`: файл жив, юнит всё ещё RUNNING и
  `now - ctl_since_ms > GRACE_MS` → `ctl-kill` (событие, Ст. 6) и
  SIGKILL группы (`kill(-pgid)` с fallback по pid);
- казнь законом: `sup_kill = 1` — лестницу не растит;
- статус-срез продолжает нести `"ctl_down":1` до снятия файла;
- дедупликация `ctl-drop` (второй пункт слепой зоны ТЗ-5): чужое имя в
  ctl-каталоге пишется в журнал один раз на файл (статический реестр
  последних 8 имён), не каждую итерацию.

## Граница

- Потолок Ст. 1: +≈10 строк к 654 → Поправка №6 одним атомом (656 → 672).
- `GRACE_MS` — общий констант-бюджет прощания (Ст. 11), нового таймера не
  заводим.

## Приёмки

1. Демо: юнит с `trap '' TERM` (игнорирует TERM) — после ctl-down живёт
   ≤ GRACE_MS, затем `ctl-kill` и exit по сигналу 9; сироты 0.
2. `make audit` → OK (`ctl-kill` в VALID_EVENTS, каждый подтверждён exit).
3. Отрицательный тест расширен: `ctl-kill` без последующего exit → FAIL.

## Отчёт о исполнении (2026-11-10)

Исполнен одним атомом с Поправкой №6. `ctl_since_ms` в unit_t,
ставится при появлении .down; эскалация в `poll_ctl()`: (ctl_down ||
retired) && RUNNING && now-ctl_since_ms > GRACE_MS → `ctl-kill`
(с why: ctl/reload) + SIGKILL группы, sup_kill=1. ctl-drop — реестр
последних 8 имён, один раз на файл. Приёмки: `make demo-v6` — stubborn
с `trap '' TERM` пережил TERM, добит через GRACE_MS (exit по сигналу 9,
stopped reason ctl-down); подделка C (ctl-kill без exit) ловится в
`negative_ctl_test.py`; сироты 0. Потолок Ст. 1: 720 → 752 (707 → 732).
