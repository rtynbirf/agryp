# Тикет 007 · Namespace-клетка попыток: pid/mount рядом с памятью

Роль: ЯДРО (контракт — AGENTS.md §3). Статус: done (отчёт ниже). Виток: 7.
Приоритет: высокий. ЦУ Хозяина (Виток 6): коллеги, клетка памяти (Ст. 15)
одна — без соседней стены агент видит чужие pid и чужой mount.

## Задача

Школа контейнеров, но по-нашему — громко и опционально:

- ключ `.agent`: `jail = pid | pid,mount` (по умолчанию пуст — без клетки);
- в ребёнке до exec: `unshare(CLONE_NEWPID)` (+`CLONE_NEWNS`) — попытка
  живёт в своей комнате имён; внутри — re-exec по договору;
- среда не даёт unshare (EPERM) — loud `jail-skip` с errno (Ст. 6, как
  `cgroup-skip`), работа дальше; молчаливой усечки нет;
- событие журнала `jail-skip`; в статус-срезе — `"jail":1`;
- не путать с Docker: без образов, без сетей, без слоёв — только комнаты
  имён у процесса, который и так первоклассник (Ст. 4).

## Граница

- Потолок Ст. 1 — по факту; Поправка одним атомом (код + статья +
  проверка, Ст. 16).
- Сеть не изолируем (агенту нужен мир); user-ns не трогаем (риск
  безопасности выше пользы).

## Приёмки

1. `make clean && make 2>&1 | grep -i warning` → пусто.
2. Демо: юнит с `jail = pid` живёт; в журнале `jail-skip` при EPERM
   (песочница) — громко; сироты 0.
3. `make audit` → OK (`jail-skip` в VALID_EVENTS).

## Отчёт о исполнении (Виток 7, 2026-11-07 — исполнено автором лично)

Статус: **done**. Исполнитель: agryp (мандат Хозяина: «они не делают —
делай сам»); коллеги получили готовое ядро.

- Ключ `jail = pid | pid,mount` — `parse_jail()` (неизвестное слово —
  вслух в stderr, Ст. 6).
- Вход в комнату — родиться в ней: `clone(CLONE_NEWPID[|CLONE_NEWNS])`
  вместо fork; ребёнок супервизора и есть PID 1 своей комнаты —
  геометрия попытки не меняется (группа, PDEATHSIG, waitpid).
- Mount-ветка: `/` рекурсивно private (MS_REC|MS_PRIVATE) — propagation
  наружу закрыт; неудача — вслух в stderr.
- Прокси `jail_term` — PID 1 комнаты глух к TERM без обработчика
  (pid_namespaces(7)); умирает так же, как умер бы без клетки.
- EPERM → loud `jail-skip` с errno, клетка снимается, работа дальше
  (как cgroup-skip, Ст. 15); reload перевзводит клетку.
- `"jailed"` в событии spawn, `"jail"` в статус-срезе.
- Доказательства: `make demo-jail` — в песочнице jail-skip errno 1
  (EPERM), оба юнита живы, сироты 0, `make audit-jail` OK; аудитор
  ловит молчаливую усечку и двух правд (jail-дисциплина).
- Граница уважена: сеть не изолируем, user-ns не трогаем, Docker-штук
  нет. Потолок Ст. 1 — в атоме Поправки №8 (820 → 880).
