# Тикет 005 · SIGHUP-reload: перечитать каталог юнитов без смерти детей

Роль: ЯДРО (контракт — AGENTS.md §3). Статус: done (отчёт ниже). Виток: 6.
Зависит от: тикет 004 (по порядку исполнения, не по данным).

## Задача

Школа systemd (`daemon-reload`): конфигурация меняется без кровопролития:

- `SIGHUP` супервизору → перечитать `*.agent` каталога юнитов;
- живые попытки НЕ умирают: изменения ключей (`budget-sec`, `token-budget`,
  `mem-max-mb`, `cooldown-ms`...) применяются к юниту на следующей попытке
  или сразу, где это безопасно (дедлайн бюджета пересчитывается от неё);
- новый `*.agent`-файл → юнит появляется и стартует; удалённый файл →
  юнит получает graceful-stop по Ст. 9;
- событие `reload` с числами (добавлено/изменено/удалено) — Ст. 6;
- cgroup-комнатки: создание для новых, честный `cgroup-skip` при отказе.

## Граница

- Перезапуск конкретного юнита остаётся за `agrypctl stop/start` (Виток 5) —
  reload не про жизни, а про договоры.
- Потолок Ст. 1 — по факту; Поправка одним атомом.

## Приёмки

1. Демо: после SIGHUP добавленный юнит живёт, изменённый бюджет виден в
   статус-срезе без смерти попытки, удалённый — умер graceful.
2. `make audit` → OK (событие `reload` в VALID_EVENTS, счётчики сходятся).
3. Сироты 0.
