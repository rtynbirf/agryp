## Задача

Три суммы одной формулы (T06, школа journald + node_exporter textfile):

- **Экспорт метрик в файл** (Ст. 13 — файл вместо сокета): каждую итерацию
  цикла супервизор пишет `<dir>/.agryp-metrics.prom` атомарно (tmp + rename)
  в формате Prometheus/OpenMetrics textfile: `agryp_up_ms`, `agryp_units`,
  `agryp_orphans_total`, `agryp_reloads_total`, `agryp_rotations_total` и по
  юниту — attempts/exits_ok/exits_fail/budget_kills/token_kills/tokens_total/
  restarts/fail_streak/ctl_down. Читатель — любой мировой инструментарий
  (textfile collector); `agryp metrics` / `agrypctl metrics` читают тот же
  файл — второй источник правды не заводится. На выходе unlink (Ст. 13).
- **Журнал-ротация с пломбой**: событие двойной летописи — stdout (транскрипт)
  и файл `<dir>/.agryp-journal.ndjson`. По достижении потолка
  (`--rotate-bytes`, по умолчанию 256 КБ) хвост отрезается атомарно
  (rename-цепочка, ROTATE_KEEP=3), а в НОВЫЙ журнал первой строкой ложится
  реестр-печать: `{"event":"rotate","seal":"<sha256 всего отрезанного файла>"}`.
  Подделка любого байта хвоста (включая середину) меняет хеш — аудит
  `tools/journal_audit.sh` даёт точный приговор; цепь печатей тянется через
  ротации. SHA-256 — компактная самодостаточная реализация (FIPS 180-4),
  ноль зависимостей (Ст. 1).
- **Сигнатуры юнитов**: договор подписывается при boot и при каждом reload —
  `unit-sign` с `old`/`new` (sha256 байт *.agent) и `mtime`. «Кто менял» мы
  не различаем (агентов не подписываем — названо вслух); «ЧТО именно
  поменялось» — машинный факт: дифф двух хешей, воспроизводимый sha256sum.

## Граница

- Ротация — только журнала супервизора; вывод агентов живёт в транскрипте
  stdout и ротируется внешним миром, как жил.
- Метрики — файл, не сервер: текстовый формат, ноль сокетов (Ст. 13 не тронута).
- Подпись — хеш файла договора; содержательный дифф полей — дело diff-инструмента.

   attempts и exits_ok в .prom == журналу транскрипта; `agryp metrics`
   байт-в-байт == файл; после смерти супервизора .prom снят.

   запечатаны; `tools/journal_audit.sh` — цепь цела; негативная проба:
   подделка середины .2 поймана с приговором «ПОДДЕЛКА … журнал лжёт».
3. `make demo-sign`: unit-sign при boot (old:null) и после подмены договора
   (old≠new, оба 64-hex, mtime); old-хеш воспроизводится sha256sum; дети живы
   (spawn 1, бюджет применился к живой попытке), сирот 0.
