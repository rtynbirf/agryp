# Тикет 001 · agrypctl: start/stop файлами-договорами

Роль: ЯДРО + ДОКТОР (контракт — AGENTS.md §3). Статус: done (2026-11-07).
Виток: 5.

## Задача

Управление юнитом без сокетов — только файловая система (Ст. 13):

- `agrypctl stop <unit>` создаёт `<dir>/.agryp-ctl/<unit>.down`;
- ядро в каждой итерации цикла читает ctl-каталог: файл `.down` жив →
  SIGTERM группе попытки, рестарт-политика юнита заморожена, пока файл жив;
- `agrypctl start <unit>` снимает файл → юнит живёт по своей политике;
- события журнала: `ctl-down`, `ctl-up` (Ст. 6: ничего не происходит молча);
- `agrypctl status` — уже есть: `agryp status` (Ст. 13), не дублировать.

## Граница

- Потолок Ст. 1: ядро растёт ≈ до 650 строк → Поправка №4 одним атомом
  (код + статья + проверка, Ст. 16).
- `agrypctl` — один POSIX sh-файл, ноль зависимостей кроме coreutils.
- Никаких сокетов, FIFO, HTTP — только файлы (HTTP API zeptopm отвергнут).
