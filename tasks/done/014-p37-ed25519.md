# Тикет 014 · П37 (волна ×6): настоящий ed25519 в подписанных конвертах + AgentCard из `agrypctl card`

Роль: ЯДРО-приближённые инструменты (`tools/`, `vendor/`, `demo/`, `tests/`)
+ конституционный атом (Поправка №12). Ядро C (`src/agryp.c`) не тронуто —
1196/1196 строк, потолок Ст. 1 стоит. Статус: done.
Источник: issue #6 (ПРЕДЛОЖЕНИЕ-37, P1, приёмка машинная). Хвост 🟡 тикета 013
(«full ed25519 — при появлении std-only реализации») закрыт этой волной.

## Задача (волна ×6, мандат роя)

1. **ed25519-подпись конвертов крови/событий**: overseer проверяет подпись
   fail-closed (битая/отсутствующая/чужая/повторная = отказ завода юнита).
   Примитив — на C: вендорить МИНИМАЛЬНУЮ публичную реализацию с
   сохранением лицензионных шапок, чистый C без внешних зависимостей.
2. **A2A AgentCard**: `agrypctl status` (CLI репо) отдаёт JSON Agent Card;
   endpoint — живое (реальные артефакты супервизора, проверяемые прямо
   сейчас).
3. **Unit-тест «битая подпись → отказ»**: зелёный прогон доказывает
   fail-closed; тест валидации карточки по схеме (JSON-схема в `tests/`).

## Решение

- **Вендор**: [orlp/ed25519](https://github.com/orlp/ed25519), upstream-коммит
  `b1f19fab4aebe607805620d25a5e42566ce46a0e` (2022-10-03), лицензия zlib —
  `vendor/ed25519/` (LICENSE.txt сохранён, файлы verbatim; взяты fe/ge/sc/
  sha512/keypair/sign/verify + precomp_data.h; НЕ взяты add_scalar/
  key_exchange/seed/test*). Provenance — `vendor/ed25519/VENDOR-NOTES.md`.
- **Единственный собственный C вне ядра**: `tools/ed25519tool.c` (~190 строк,
  тонкий адаптер: keygen/pub/sign/verify, seed можно через env
  AGRY_ED25519_SEED). rc: 0 — годна, 1 — подпись не сходится, 2 — битый вход.
- **Конверты v2**: `{"v":2,"alg":"ed25519",...,"sig":{"key_id":"16hex",
  "pub":"64hex","sig":"128hex"}}`; `key_id = sha256(pub)[:16]`. Легаси v1
  (sha256-wots ×4) сохранён (`WotsCellSigner`): диспетчер `verify()` честно
  проверяет оба формата, но дверь по умолчанию доверяет ТОЛЬКО ed25519 —
  незнакомый alg = отказ (поле alg — не рекомендация, а закон двери).
- **Поправка №12 (Ст. 1)**: счёт границы заперт машиной — ядро 1, tools 1,
  vendor 7, вне зон 0; числа объявлены в статье и проверяются
  `tools/check_constitution.py` (расширен в том же атоме; негативная проба:
  подброшенный .c вне зон — «КОНСТИТУЦИЯ ЛЖЁТ»).
- **AgentCard**: `agrypctl card` ≡ `agrypctl status --card` —
  `tools/agentcard.py build` из живого статуса + свежего `.prom`; карта
  валидируется схемой ДО выдачи; `x-agryp.signing` (alg/envelope_version/
  tool/key_id_format) добавлен в карту и в схему (same atom). Копия схемы
  в `tests/a2a-agentcard.schema.json` — дрейф заперт тестом.

## Ограничения (честно)

- Транспорт конвертов и карты — файл (Ст. 13): сетевого endpoint у карты
  нет (сокеты в доме запрещены); сетевой контур — вне P1-приёмки.
- seed клетки = derive_seed(secret) — 1024×sha256 растяжка; это не argon2:
  рабочий ключ клетки должен быть длинным случайным (32B), человеко-пароли
  не годятся. Рабочих ключей в репо нет; тестовые — одноразовые, TEST ONLY.
- Сверстники: ed25519-верификация в самом ядре C (событие отказа в журнале)
  остаётся хвостом — пока дверь на границе клетки (python), ядро не знает
  о подписях (потолок Ст. 1 не трогали намеренно).
