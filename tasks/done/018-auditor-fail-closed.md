# Тикет 018 · аудитор против выдумки: fail-closed + негативные пробы (Поправка №16)

> Виток 11 · открыт и исполнен 2026-11-10 (инициатива Хозяина, чат;
> дверь — `docs/SVERKA-VITOK6-PARALLEL.md`, предложения 4 и 5.2; ТЗ-10)

## Суть

Аудитор транскриптов был fail-open в трёх местах: битый путь к журналу
ронял его трейсом (код 1, но приговор нечестный), пустой каталог юнитов
молча подставлял дефолт `cooldown-ms=1000` (проверка лестницы против
выдуманных договоров — тот самый грех 5.2), а не-целые `ts`/`up_ms`
ранили сравнение. Мировая разведка 2026-11-10 (агент 2-b): канон
fail-closed — проверка TLS в curl/OWASP («нет доказательств — нет
вердикта OK»); «проверяльщик проверяльщика» — Thompson, Reflections on
Trusting Trust + mutation testing (Stryker): пробы генерируются
систематически, каждая обязана краснеть С ТОЙ ПРИЧИНОЙ.

## Договор

- Нет журнала / журнал не декодируется / пуст каталог юнитов / юнит без
  договора — красный с честной причиной, код 1, ноль трейсов.
- Юнит без договора в каталоге — красный, КРОМЕ двух честных случаев:
  `unit-removed` в транскрипте (демо reload удаляет `*.agent` на живую —
  история длиннее каталога) и упоминание только через `report-drop`
  (рапорт заведомо неизвестного юнита — Ст. 14 сама кричит «мы его не
  знаем»; фантом не имеет ни договора, ни смерти, ни одного лишь
  report-drop).
- `AGRY_AUDIT_UNITS` — дополнительные каталоги договоров через двоеточие
  (пробы несут свои; прод-поведение не меняет).
- `make audit-neg`: канарейка `tests/positive/canary.jsonl` обязана быть
  зелёной; каждая проба `tests/negative/*.jsonl` обязана быть красной С
  ТОЙ ПРИЧИНОЙ, что в `tests/negative/MANIFEST.tsv` — и «пропустил
  выдумку», и «красный не по делу» — провал пробы.
- 13 проб: фантом, нет shutdown, ложь счётчика, ложь ready, казнь без
  трупа, спавн поверх живого, жизнь после shutdown, битый JSON,
  NUL-дыры, ложная ступень лестницы, открытая скобка reload (связка с
  тикетом 017), второй ready, дыра в нумерации попыток.

## Приёмка (факт, 2026-11-10)

- `make audit-neg`: канарейка зелёная, 13/13 проб красных по делу, rc=0.
- Урок live + CI: правило сразу поймало ЧЕСТНЫЙ кейс — beta в
  reload-демо (договор удалён на живую) — уточнено `unit-removed`;
  первый CI-прогон поймал ghost (report-drop из run_demo.sh, файла
  ghost.agent в git нет) — уточнено report-drop-исключением, канарейка
  несёт report-drop и обязана оставаться зелёной; фантом по-прежнему
  красный.
- Полная батарея 13/13 rc=0 + все аудиты + `audit-neg` + `catalog-guard`
  — зелёные после правила; ядро не тронуто (1320/1330, Ст. 1 цела).
- CI: шаг `make audit-neg` встроен в джобу audit — проверяльщик
  проверяется на каждой сборке.
- Пробы детерминированы: регенератор `scripts/gen_fixtures.py` (вне
  репо) — файлы проб лежат в `tests/` как контракт.

## Границы

Fail-closed закрыл честность ВХОДА аудитора; подпись журнала ( ed25519
конверты витка 10) закрывает честность САМОГО журнала — связка
«аудитор сначала верит печати, потом разбирает смысл» — дверь следующей
волны. Мутационное выращивание проб (автогенерация из честного журнала)
— та же дверь.
