## 1. Задачи витка (постановка учителя)

- **Т1. ЯДРО — namespace-клетка** (тикет 007): ключ `jail = pid | pid,mount`
  (по умолчанию пуст); попытка рождается в собственных комнатах имён —
  не `unshare` после рождения, а `clone(CLONE_NEWPID[|CLONE_NEWNS])`:
  ребёнок супервизора и есть PID 1 новой комнаты — без среднего процесса,
  сиротной геометрии и второго waitpid; mount-ветка сразу делает
  `/` рекурсивно private (MS_REC|MS_PRIVATE) —Propagation наружу закрыт.
  Среда не даёт unshare (EPERM) — loud `jail-skip` с errno, работа
  дальше без клетки; `"jailed"` в событии `spawn`, `"jail"` в статус-срезе.
  Не Docker: без образов, сетей и слоёв; user-ns не трогаем. Поправка №8.
- **Т2. ЯДРО — токен-отчёт стримом** (тикет 009): урок sd_notify доведён
  до конца — канал тот же (env + файл), будилка другая: env
  `AGRY_SUPER_PID`, агент после записи в отчёт бьёт `SIGUSR2` — петля
  просыпается немедленно, не на тике 250 мс. Обратная совместимость
  полная: старый протокол витков 1–6 работает как работал (молчащий
  агент собирается раз в итерацию). Поправка №8.
- **Т3. ДОКТОР — мост `.agent` ↔ systemd unit** (тикет 008): трансляторы
  `tools/agent2unit.sh` и `tools/unit2agent.sh` (POSIX sh) — файл
  порождает файл; ядро не растёт ни на строку (Ст. 1 не тронута этой
  задачей); честная таблица потерь в README; тест туда-обратно.
- **Т4. АУДИТОР**: словарь + `jail-skip`; дисциплина клетки — юниту с
  `jail` в конфиге положена ровно одна из двух правд: `jailed` в спавне
  или `jail-skip` (молчаливой усечки нет); после `jail-skip` спавн обязан
  состояться (работа дальше).
- **Т5. ДОКТОР**: README (формат юнита, словарь событий, разделы клетки/
  стрима/моста), ROADMAP, тикеты 007–009 → done с отчётами.

## 2. Учителя и отвергнутые пути

- Учитель Т1 — школы контейнеров (Docker/LXC) и systemd-изоляция
  (`PrivatePID=`). Взято одно зерно: комнаты имён у процесса, который и
  так первоклассник. Отвергнуты: образы/слои/сети (нам не нужно); user
  namespace (риск безопасности выше пользы — ЦУ тикета 007); `unshare()`
  в ребёнке после fork (родившийся остаётся в старом pidns — изоляции
  нет; честный вход в новую комнату — только родиться в ней, отсюда
  `clone()` вместо `fork()`).
- Учитель Т2 — systemd `sd_notify`: канал через env, уведомление —
  событие. Отвергнут **FIFO** (`AGRY_TOKEN_PIPE`, тикет 009, вариант 1):
  в этом доме сокет, FIFO и HTTP запрещены (AGENTS.md §2, Ст. 13) —
  канал обязан оставаться файлом, запись ≤ PIPE_BUF атомарна и у файла.
  Отвергнут и слепой stat()-опрос в 250 мс (вариант 2): латентность
  остаётся тиком итерации. Выбран третий путь: файл + сигнал-будильник
  `SIGUSR2` — тот же приём, что у статус-среза (`SIGUSR1`, Ст. 13):
  файл — истина, сигнал — звонок.
- Учитель Т3 — systemd-ферма уже живёт со своим супервизором (Ст. 5):
  не пере-делывать его, а разговаривать на его языке. Отвергнут вызов
  systemctl из ядра — трансляция это текст→текст; эквивалентность не
  обещается — обещается честная таблица потерь.

## 4. Границы витка (что НЕ делаем)

- Сетевые namespace — никогда: агенту нужен мир (ЦУ тикета 007).
- user namespace — не трогаем (риск выше пользы).
- Образы, слои, pivot_root — это Docker, не мы.
- systemctl из ядра — никогда; мост живёт в `tools/`.
- Виток 8 (бенчмарк против сверстников, public-переворот) — вне витка 7.

## 5. Слепые зоны

- **jail без CAP_SYS_ADMIN проверен, jail с ним — нет**: в песочнице
  clone с CLONE_NEWPID даёт EPERM (доказано демо), но путь `jailed`
  исполнен только на бумаге кода — живой прогон возможен на хосте с
  CAP_SYS_ADMIN (записать в виток 8: прогон в привилегированном
  контейнере, `jailed:3` в транскрипте).
- **Сигналы коалесцентны**: десять USR2 подряд — одно пробуждение; это
  нормально (файл — истина, сигнал — звонок), но латентность измерена
  сверху, не посылками.
- **`setpgid` через границу pidns** не проверен живьём (та же причина,
  что и в первом пункте): код держит страховку `kill(pid)` при отказе
  `kill(-pgid)` — прежнюю дисциплину не теряем.
- Мост не проверяет семантику `RuntimeMaxSec` (у systemd это TERM→KILL
  сервиса, у нас — SIGKILL группы попытки): таблица потерь честно
  называет это «смерть той же сути, другим хватом».
