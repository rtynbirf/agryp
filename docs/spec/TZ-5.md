# ТЗ-5 · Виток «Руки без сокетов» (agrypctl)

Статус: исполнен · Дата: 2026-11-07 · Постановка: agryp (учитель, полимат)
Мандат Хозяина: «делай 5 виток, пуш своим коллегам в репо». Витки 1–4
исполнены, ученик стал учителем: постановку, параллелизацию и связывание
веду сам, коллегам-агентам — тикеты-ЦУ.

## 1. Задачи витка (постановка учителя)

- **Т1. ЯДРО — ctl-контур** (тикет 001): `<dir>/.agryp-ctl/<unit>.down` —
  файл-договор. Файл жив → SIGTERM группе попытки, рестарт-политика
  заморожена; казнь — законом (лестницу не растит), остановка с
  `reason:ctl-down`. Файл снят → `ctl-up`: новая попытка с чистой
  лестницей, минуя cooldown. Boot уважает `.down` прошлой жизни. События
  `ctl-down` / `ctl-up` / `ctl-drop` (Ст. 6); `"ctl_down"` в статус-срезе.
- **Т2. agrypctl — один POSIX sh-файл**: stop / start / status-passthrough;
  ноль зависимостей кроме coreutils; запись атомарна (tmp + rename, Ст. 13).
- **Т3. АУДИТОР** (тикет 002): ctl-события в словаре; дисциплины — спавн
  при живом .down невозможен, ctl-up без ctl-down — ложь, казнённая
  попытка обязана получить exit и остановиться с `reason:ctl-down`;
  отрицательный тест `demo/negative_ctl_test.py` скармливает аудитору
  две подделки и требует точного приговора.
- **Т4. ДОКТОР — Поправка №4 одним атомом**: Ст. 1 потолок 608 → 656
  (факт: 607 → 654), Ст. 6 — ctl-события, Ст. 13 — управление файлом-договором;
  README, ROADMAP, AGENTS.md.
- **Т5. ЦУ коллегам**: тикеты 004 (finish-хук), 005 (SIGHUP-reload),
  006 (эскалация ctl-stop) — в `tasks/open/`; 001–002 закрыты в `tasks/done/`.
- **Т6. Мандат Хозяина на пуш**: репо `rtynbirf/agryp` создано по
  чек-листу github-runbook; пуш main, тег `v0.5.0`.

## 2. Учитель и отвергнутые пути

- Учитель — s6 (`s6-svc -d/-u`): управление через файловую систему.
- Отвергнут: HTTP-API сверстника zeptopm (сокет против Ст. 13), FIFO
  (состояние гонки без атомарного rename), сигнал юниту напрямую
  (не выражает «заморозить политику до отмены»).

## 3. Приёмки витка (все — команды)

1. `make clean && make 2>&1 | grep -i warning` → пусто; `ldd agryp` → только libc.
2. `make demo && make audit` → OK (регрессия витков 1–4: 43 события + 43 строки агентов).
3. `make demo-ctl` → worker казнён без единого рестарта, ghost жив
   (заморозка пер-юнит), ctl-up → attempt 2, сирот 0.
4. `make audit-ctl` → OK по обоим пунктам: аудит ctl-транскрипта + обе
   подделки пойманы (спавн при живом .down; ctl-up без ctl-down).
5. `wc -l src/agryp.c` → ≤ 656 (факт 654).
6. `grep -rEn 'ghp_[A-Za-z0-9]{20,}' . --exclude-dir=.git` → пусто.

## 4. Границы витка (что НЕ делаем)

- Эскалация ctl-stop: TERM-упрямый юнит живёт до бюджета или ручного KILL —
  цена строк против потолка; вынесена в тикет 006 (виток 6).
- Дедупликация `ctl-drop`: чужой .down пишет событие каждую итерацию —
  вслух, но шумно; точечная дедупликация — в тикет 006.
- Чужие репо аккаунта не трогаются (орбиты §1.1 AGENTS.md); репо agryp —
  private, перевод в public — виток 8 (v1.0).

## 5. Слепые зоны

- ctl-каталог сканируется opendir'ом каждую итерацию (250 мс) — для фермы
  64 юнитов это 64 readdir'а/с; при росте MAX_UNITS мерять цену (виток 8).
- Рейт-лимиты GitHub API не исчерпаны; факт создания репо — срез 2026-11-07.
- Внутри ctl-демо есть окно между `mv` файла и ближайшей итерацией —
  природа файл-API: команда исполняется за ≤ 250 мс, не мгновенно.
