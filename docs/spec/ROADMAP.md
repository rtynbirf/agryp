- Namespace-клетка попыток (Ст. 15-сосед, тикет 007): ключ
  `jail = pid | pid,mount`; вход в комнату — родиться в ней:
  `clone(CLONE_NEWPID[|CLONE_NEWNS])` вместо fork — ребёнок и есть PID 1
